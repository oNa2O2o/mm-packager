# 可选模块：MM-JP 尾板（一镜到底 3D 卡片）

2026-10-27 用户验收的 JP 通用尾板（定稿 v19A）。17.3 s，1080×1920，30 fps，带女王02 口播 + 钢琴弦乐 + 音效。
**这是可选项**：包装 JP 素材时，在定方案阶段问用户「片尾用 JP 尾板模块，还是用模板 / 自定义片尾」。用户选了才加。

## 内容（不要改动，改了要重新验收）
| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0–3.0 | 光点炸开 → 角色卡网络展开 | あなたの選択が、[展開]を変える |
| 3.2–6.8 | 镜头依次飞到 3 张对比卡（害羞俯拍 / 高冷仰拍 / 成熟仰拍），卡上弹聊天气泡 | 恥じらう子も、冷たい子も、大人の子も。みんな、あなたに[夢中] |
| 6.6–8.2 | 拉远蓄力 → 弹弓式冲进角色卡螺旋长廊 | |

文案、口播、时间轴固定（日语，口播和动画逐句对齐）。**换文案 = 重新配音 + 重新对时间，不在本模块配置范围**，需要时向用户申请单独做。

## 用法
`$EC` = `python "$SK/modules/jp-endcard/endcard.py"`（需要 `playwright`、Chrome、ffmpeg；本机已配好）

```bash
# 1. 默认配置（秒出：直接复制定稿成片）
$EC render --out <工程>/包装素材_尾板/尾板.mp4
# 在 timeline.json 里作为 video clip 接在末尾，start = 正片结束时间

# 2. 换角色（可选）：先出静帧看，再 render（会逐帧渲染约 30 分钟，后台跑）
$EC stills --config cfg.json --out "<工程>/包装素材_尾板/静帧"
$EC render --out <工程>/包装素材_尾板/尾板.mp4 --config cfg.json

# 3. 只要一条尾板 mp4
$EC render --out "<目录>/尾板.mp4" [--config cfg.json]
```

放进 timeline：
- 尾板 mp4 放在 `<工程>/包装素材_尾板/`（默认叫 `MM-JP_尾板_定稿.mp4`，自定义叫 `MM-JP_尾板_<配置哈希>.mp4`，同配置不会重复渲染），配置另存 `尾板配置.json`。
- 渲染出的 mp4 作为 video clip 接在片尾（`fit: cover`），同 src 的 audio 条目放口播。
- 正片 BGM 在尾板起点前淡出 0.5 s（在 timeline 里给 BGM 条目设 duration + fadeOut）。
- 然后照常 render.py 出预览、目视。

## 配置 cfg.json（全部可省略）
```json
{
  "heroes": [
    {"card": "F:/…/害羞角色.png", "tag": "照れ屋", "chat": "え…わ、私でいいの？", "tint": "#F6A3E0", "angle": "high"},
    {},
    {"card": "F:/…/成熟角色.png"}
  ],
  "addCards": ["F:/…/本条素材角色1.png", "F:/…/角色2.png"],
  "replaceAllCards": false
}
```
- `heroes`：正好 3 个，顺序 = 害羞 / 高冷 / 成熟；`{}` 表示该位保持默认。`card` 可填图片绝对路径或内置卡下标；`tag`、`chat` 显示在卡片气泡上（日语，**必须来自全量文案或用户批准**）；`angle` = `high`（俯拍，弱势角色）/ `low`（仰拍，强势角色）。
- `addCards`：追加角色图（任意尺寸竖图，自动居中裁成卡片），优先进开场角色网，同时进长廊。
- `replaceAllCards: true`：不用内置 27 张卡，只用 addCards + heroes（总数至少 8 张）。
- 角色图要求同主视觉规范：胸部 ≤ C、无乳沟、不露脚，衣服保持原色原材质。

## 坑
- 自定义渲染约 30 分钟（每帧最多 24 个子帧做运动模糊）：用 `nohup … &` 后台跑，轮询日志；不要放在 600 s 超时的前台命令里。
- 用户验收过的点（改引擎时别退回）：开头连线不能压在卡上/连向空处；第三张卡之后镜头速度连续、不停顿；卡片吸入 Logo 的声音必须用 BGM 同源素材（倒放收尾钢琴弦乐），**不要合成音效、竖琴、嗖声、咚**；左上角用 Logo 字标图，不要手打 MIRAIMIND。
